## Ответы на вопросы задания
* **Почему цикл завершится:**
  Цикл `for` по объекту `range` или итерируемой последовательности завершается автоматически, когда в ней заканчиваются элементы. Цикл `while` завершается, когда условие в его заголовке становится ложным (`False`), либо при выполнении команды `break` внутри тела цикла.

* **Почему `range(a, b)` не всегда соответствует условию задания №1:**
  1. Функция `range(a, b)` по умолчанию не включает правое крайнее значение `b` (работает до `b - 1`). Чтобы включить число `b`, нужно использовать `b + 1`.
  2. Если первое число больше второго (`a > b`), стандартный вызов `range(a, b)` вернет пустую последовательность. Для корректного счета в обратную сторону необходимо явно указывать отрицательный шаг: `range(a, b - 1, -1)`.
